# Jira Conventions

## Sprints

Most teams run two-week sprints starting on Wednesday. Sprint planning is Wednesday morning; the sprint review and retro are on the second Tuesday afternoon. New joiners are invited to these ceremonies by their team lead, usually from their second sprint.

## Tickets

Every ticket needs a clear summary, acceptance criteria and a story point estimate before it enters a sprint. Link tickets to the client project code (for example HALO-123). Move a ticket to Done only when it meets the Definition of Done (DoD).

## Getting access

Access to a project board is requested through an Internal Change Request (ICR) in Jira. Your manager usually raises this during your second week.

## Azure DevOps

Some older projects still live in Azure DevOps while the MERIDIAN migration finishes. Your team lead will tell you which tool your project uses.
